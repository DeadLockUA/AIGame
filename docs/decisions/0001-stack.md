# ADR 0001. Стек

Решение: ванильный JavaScript (ES-модули) и Canvas 2D, без сборки и без внешних зависимостей во время выполнения. Папка `game/` публикуется как есть.

Причины: минимум зависимостей (требование заказчика), быстрый запуск на телефоне, логика мойки не зависит от DOM и проверяется в Node (`node:test`), графика и интерфейс проверяются Playwright в мобильной эмуляции.

Ассеты: только процедурные (Canvas/SVG, WebAudio). Внешних ассетов нет, `docs/CREDITS.md` фиксирует это.
