# Публикация

Игра — статический сайт из папки `game/`. Сборки нет.

## GitHub Pages
1. Один раз: репозиторий → Settings → Pages → Build and deployment → Source: **GitHub Actions**.
2. Любой пуш в `main` (или ручной запуск workflow `Pages`) публикует `game/`. Пока Pages не включён, workflow завершается успешно и пишет в журнал, что публикация пропущена.
3. Адрес: `https://<владелец>.github.io/<репозиторий>/`.

## Локально
`npm run serve` и открыть адрес. Для проверки офлайн-режима открой без `?nosw`.

## Обновления у игроков
`tools/build-precache.mjs` (запускается в workflow и обязателен перед коммитом: `npm run precache`) пересчитывает список файлов и вшивает версию в `sw.js`. Новая версия подхватывается при следующем открытии игры.
