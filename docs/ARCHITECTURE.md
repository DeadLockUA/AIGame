# Архитектура

## Слои
1. **Данные** (`game/js/data/`): снаряжение, сюжет по районам, находки, достижения, тексты, улучшения мастерской, калибровка заказов.
2. **Ядро** (`game/js/core/`): состояние и действия, экономика, прогрессия, адаптивная сложность, советы по набору, сохранение. Чистая логика: работает в Node (юнит-тесты, бот).
3. **Мойка** (`game/js/wash/`): `engine.js` — сетка 72×108, слои грязи по 8 типам, пена, влага, три фазы; `dirtgen.js` — генерация грязи по профилю; `view.js` — отрисовка; `fx.js` — частицы.
4. **Ковры** (`game/js/carpet/`): `render.js` собирает ковёр (стиль + ткань + свет + кромка + бахрома), `styles/*.js` — 19 стилей орнаментов, `kit.js` — общие примитивы рисования.
5. **Интерфейс** (`game/js/ui/`): экраны на чистом DOM (`h()`), без фреймворков.
6. **Звук и отклик** (`game/js/audio/`): WebAudio-синтез эффектов и динамической музыки, вибро.

## Мойка: модель
Ковёр — сетка клеток. Каждая клетка хранит количество грязи по типам, «разрыхлённую» часть, пену (и какое средство, возраст пены), влажность.
- **Пылесос** убирает сухие типы (пыль, шерсть, песок) по сродству инструмента; фильтр забивается.
- **Средство** наносит пену. Пена «созревает» (`dwell`) и разрыхляет грязь пропорционально сродству средства к типу грязи.
- **Смыв** убирает разрыхлённое; неразрыхлённое — слабо. Сухое под водой становится мокрой грязью. Пар работает по жиру, плесени, въевшейся грязи.
- **Чистота** = 1 − оставшийся взвешенный вес / исходный. Остатки пены штрафуются.
- **Находки** раскрываются, когда под ними чисто.
- **Квирки** меняют правила (зарастание, призраки, тьма и т. д.).

## Экономика и прогресс
Заказ → набор → мойка → `settle()` (оплата по чистоте, бонус за время, находки) → репутация, подписчики → пост в ленте. Подписчики и закрытый сюжет района открывают следующий район. Время заказа = время бота на типичном наборе района × 1.35 + 10 с, умноженное на адаптивный коэффициент 0.85–1.2.

## Баланс
`tools/calibrate.mjs` прогоняет бота по 60 сюжетным заказам и пишет `data/calibration.js` (время и стоимость). `tools/playthrough.mjs` проходит всю игру ботом и оценивает длительность и экономику.

## Тесты
- `tests/unit/*.test.mjs` — движок, ядро, бот.
- `tests/e2e/run.mjs`, `extra.mjs` — Playwright в мобильной эмуляции: заказ от начала до итогов, квирки, спасение, смена района, сохранение, офлайн, титры.
