# Бриф: стили ковров

Игра «Чистый ворс» — мобильная игра про мойку ковров. Главное требование заказчика: **ковры должны быть красивыми**. Это вектор, нарисованный кодом в Canvas 2D, «арт-игра» уровня хорошего мобильного релиза.

## Контракт
Файл `game/js/carpet/styles/<id>.js` экспортирует по умолчанию:
```js
export default {
  id: '<id>', name: 'Русское название',
  paint(g, rng, spec) { /* рисует тело ковра в логических координатах 360x540, начало (0,0) в левом верхнем углу тела */
    return { edge: [r,g,b], fringe: [r,g,b] }; // цвет кромки (оверлок) и бахромы
  },
};
```
- `g` — CanvasRenderingContext2D, уже масштабирован и обрезан по телу 360x540. Рисуй всё тело, включая кайму. Рендер сам добавляет ткань (сетка нитей), шум, свет, кромку 5px по периметру (держи важное дальше 6px от края) и бахрому.
- `rng` — детерминированный генератор (`rng.next()`, `rng.range(a,b)`, `rng.int(a,b)`, `rng.chance(p)`, `rng.pick(arr)`, `rng.shuffle`, `rng.fork(tag)`). **Math.random запрещён.** Один сид — один ковёр; разные сиды обязательно дают заметно разные ковры (палитра, композиция, элементы) в рамках стиля. Не менее 5 палитр и 3 вариантов композиции.
- Помощники в `game/js/carpet/kit.js` (hex, mix, lighten, darken, css, pickPalette, star, ngon, lozenge, petalPath, rosette, palmette, boteh, vine, quad, mirrorX, alongRect, rectBand, dots, polar). Пример качества и приёмов — `game/js/carpet/styles/persian.js` (симметрия через `quad`, кайма, медальон). Свои помощники пиши внутри своего файла. **Не меняй `kit.js`, `render.js`, `index.js`, чужие стили.**
- Рендер одного ковра при scale=2 должен занимать не более ~150 мс. Только 2D Canvas, без внешних ресурсов и шрифтов (текст на ковре не нужен).
- Грязь в игре коричневатая/серая/зелёная и лежит поверх ковра полупрозрачными пятнами: делай ковёр насыщенным, но с читаемыми светлыми и тёмными зонами, без однотонных заливок на больших площадях (всегда рисунок, текстура).

## Эстетика
Элементы должны быть складными: границы с повторяющимися мотивами и аккуратными углами, симметричное или осознанно асимметричное поле, иерархия (крупное – среднее – мелкое), тонкие обводки, градиенты и тени умеренно (это вязаная/тканая вещь). Культурные стили — по мотивам реальных традиций (без карикатуры). Абсурдные темы — «ковёр, но с шуткой»: всё ещё ковёр (кайма, кромка, плотный рисунок), но содержимое смешное и милое.
