# Схемы контента

Все файлы — ES-модули `export default`. Текст только на русском. Длина строк реплик — до 140 символов, названий — до 40, подписей — до 90.

## Сезон (`game/js/data/story/seasonNN.js`, NN = 01..10)
```js
export default {
  id: 1,
  name: 'Тополиная',                // название района
  subtitle: 'Спальный район, где всё началось',
  blurb: 'Одна-две фразы для карточки района',
  intro: ['реплика 1', 'реплика 2', 'реплика 3'],   // экран открытия сезона (3 реплики, голос рассказчика/кота)
  outro: ['реплика 1', 'реплика 2'],                // итоги сезона (2 реплики, мини-титры)
  orders: [ /* ровно 6 заказов, см. ниже; заказ №5 (index 4) — абсурдный */ ],
};
```
## Заказ
```js
{
  id: 's01o1',                      // sNNoK, K=1..6
  title: 'Олени тёти Вали',         // название ковра (для ленты и галереи)
  style: 'retro',                   // культура (для обычных) или абсурдная тема (для №5)
  client: { name: 'Тётя Валя', role: 'соседка с пятого этажа', avatar: { skin: 0..4, hair: 0..7, hairStyle: 0..5, shirt: 0..7, accessory: 0..5 } },
  intro: ['реплика клиента при заказе (1–2)'],
  success: ['реплика при хорошей мойке (1–2)'],
  partial: ['реплика, когда отмыто лишь на пороге (1)'],
  fail: ['реплика при провале (1)'],
  caption: 'подпись под фото в ленте фирмы, до 90 символов, с лёгким юмором',
  dirtFocus: ['mud','dust'],        // 1–3 типа, которые в этом ковре главные (только из открытых)
  quirks: [],                       // только у №5: 1 квирк из списка; у остальных пусто
  finds: ['f_key_old'],             // 0–2 id находок из каталога находок
}
```
## Находки (`game/js/data/finds.js`)
`export default [{ id:'f_...', name, desc, emoji, rarity: 'common'|'rare'|'epic', value: монеты (5..400), rep: 0..3 }]` — не менее 60 предметов, смешные и тёплые, несколько взрослых.

## Достижения (`game/js/data/achievements.js`)
`export default [{ id:'a_...', name, desc, check: 'ключ', goal: число, rewardCoins, rewardRep }]`. Ключи `check` из списка: jobs (всего заказов), perfect (идеальных моек), stars3 (три звезды), finds (находок), followers (подписчиков), coins (накоплено), fast (мойка быстрее 50% времени), noVacuum (без пылесоса), noRescue (подряд без спасения), seasons (закрытых сезонов), absurd (абсурдных ковров), owned (владение инструментами), mods (модификаторов), decor (декора), challenges (вызовов), gallery (постов). Не менее 40.
